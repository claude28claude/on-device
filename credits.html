Credits and licences

Everything this site uses is stored inside the site itself and served from the same address as the page. Nothing is fetched from anyone else's servers, which is both a privacy decision and the reason it works offline.

Bundled libraries

At this stage — the end of Phase 1 — the site uses no third-party code at all. Every line of HTML, CSS and JavaScript here was written for this project. That is not a boast, it is just what the shell needed.

Libraries arrive as the tools that need them arrive. Each one will be listed below with its version and licence before the tool using it ships. Only permissive licences are used: MIT, Apache 2.0 and BSD.

One licence still to settle

The best-known HEIC decoder for browsers is built on a library released under the LGPL, which is not one of the permissive licences this project promised to stick to. Before Phase 2 ships, either a permissively licensed decoder will be used instead, or the licence position will be stated here plainly so the choice is yours. It will not be quietly included and hoped for the best.

Fonts

None are downloaded. The site uses whichever typeface your own device already provides for its interface, which is why the first page load is so small and why there is no request to a font service.

Icons

All drawn for this project as plain shapes inside the page. There is no icon font and no icon service.

The app icons and social image

Generated by a small script in this repository that writes the image files directly, pixel by pixel, using nothing but what Node.js already includes. No image library, no design tool, no download.

This project's own licence

MIT. Use it, read it, copy it, host your own. The point of the promise on the front page is that you should not have to trust anybody, including us.
