Help

Plain answers, no jargon. If something here is wrong or unclear, that is worth knowing — the whole point of this site is that you should not have to take anything on faith.

The ten questions people actually ask

Where do my files go?

Nowhere. They are opened by your browser, changed by your browser, and saved back to your own downloads folder. At no point does a copy travel anywhere.

How can I be sure?

Switch off your wifi and use the site. It works. A site that uploaded your files could not possibly do that. There is also a live counter of every network request this page has made, and instructions for checking with your browser's own tools.

Is it free? What is the catch?

It is free, there are no accounts, no adverts, no paid tier and nothing to sign up for. The catch, if you want one, is that everything runs on your own machine, so a very large file on an old phone may be slow or may not fit in memory. The site tells you before you start, not after it crashes.

Do I need to install anything?

No. You can also install it if you want to — most browsers offer an "Install" or "Add to home screen" option — and then it behaves like any other program on your machine, including working with no connection at all.

Why does it need JavaScript?

Because the work happens on your computer. JavaScript is the thing doing the work. A site that did everything on a server would need less of it — and would have your file.

My iPhone photo will not open anywhere. Can this fix it?

That is the HEIC format, and yes, that is exactly what the image converter is for. It arrives in Phase 2. See what is built for where that stands today.

Can it open a PDF I do not have the password for?

No, and it never will. The password tool decrypts a document when you supply the correct password — for a file you own and can already open, so you can stop having to type the password every time. There is no cracking, no bypass, and no attempt to get into anything you are not entitled to open.

What happens to my files when I close the tab?

By default they are cleared. You can turn that off in Settings if you would rather your work survived a refresh. Either way, nothing is anywhere but your own device.

Something went wrong and I got an error. Now what?

Every error on this site is supposed to tell you what happened, why, and what to do next. If you got one that just says something broke, that is a bug in the site and worth reporting. Nothing was sent anywhere, whatever the error said.

Why are so many tools marked "not built yet"?

Because they are not built yet. The site is being written one phase at a time and tested with real files before anything is called finished. The alternative — a homepage full of tools that half work — is exactly what this is meant to replace.

Doing the same job over and over

If you find yourself opening the same tool every week with the same settings, make a recipe. A recipe is a name and a list of steps — shrink the photos, then strip the location, then bundle them into a zip. Drop a folder onto it and every file goes through every step in one action.

Three examples come with it, and they are ordinary recipes: open one and change anything you like. A recipe is checked before it runs, so if a step could never work on the files you have loaded, it says so before starting rather than after three minutes of work.

A step that needs a password asks you every time. Passwords are never written into a saved recipe, and never into an exported one, so a recipe file you send to somebody cannot carry one.

Not every tool can be a step. Anything that needs you to look at a particular file and make a judgement — drawing a crop box, marking words to redact, placing a signature — cannot be replayed on files it has never seen. The Recipes page lists all sixteen of those, with the reason for each.

Making it yours

Under Settings, Layout you can rename any tool to whatever you actually call it, move things up and down, and hide the ones you never use. A hidden tool disappears from the homepage and from the search box; its own page still works if you have it bookmarked. One button puts the whole list back to normal.

Renaming does not lose anything: a tool you have renamed is still found by searching for the name it came with.

The same section can turn on a sidebar down the side of the homepage, and can make the homepage open straight into a single tool if that is the only one you use. That last one steps aside once per visit — go to the homepage a second time and it stays there, so you can always get back to change your mind.

Using it without a mouse

Everything works from the keyboard. Tab moves forward, Shift Tab moves back, Enter or Space presses things, and Esc closes them. Press Ctrl K (or Cmd K) anywhere to search every tool by name or by what you want to do.

There are four more: Alt Shift H for the tool list, Alt Shift R for your recipes, Alt Shift T to show or hide the results tray, and Alt Shift Backspace to clear everything.

You can change any of them on the Settings page: press Change, then press the keys you want. Combinations the browser needs for itself — the one that reopens a closed tab, for instance — are refused with an explanation rather than quietly stolen.

Using it on a phone

Everything that can be dragged can also be tapped — there is no action that requires a mouse. Files come from your normal photo library or file picker. Large files are the one real limitation: phones give a browser far less memory than a laptop does, and the site will say so honestly before it starts rather than losing your work halfway through.

If a tool refuses your file

The most common cause by far is a file whose name does not match its contents — a photo called .jpg that is really a HEIC, or a .pdf that is really a Word document. This site checks the actual contents rather than trusting the name, and will tell you exactly what it found.
