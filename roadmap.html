What is built, and what is not

This site is being built one phase at a time. Nothing appears on the homepage pretending to work before it does. This page is the honest state of it, generated from the same list the homepage uses, so it cannot drift out of date.

Every tool

Forty-one tools are planned. A tool marked Ready has been built and tested with real files. Everything else says which phase it arrives in.

Things that may not survive

Being straight about this now rather than at the end. These are the parts most likely to be cut or delivered in a reduced form, and why.

  • Compressing a PDF. Re-encoding the pictures inside a PDF while keeping its text selectable is genuinely difficult in a browser. The reliable version turns pages into pictures, which saves a lot of space but loses selectable text. It will ship clearly labelled, or not at all.
  • AVIF export. Only some browsers can write this format. It will be best-effort with a plain warning, never a silent failure.
  • Password-protected zip files. Reading them is fine. Creating them only works in formats that are either weak or poorly supported. The "Lock a file" tool does this properly instead.
  • Video and audio. Works, but slowly, and needs a large one-time download. Last, and only if everything else is finished.
  • Very large files on a phone. Frequently impossible. The site measures the available memory and refuses before starting, with the real numbers, rather than crashing your tab.
  • Reading QR codes — not shipped. The QR generator is built and verified against the specification’s own published test data. The reader is not. The library chosen for it would not decode a single code during testing, including codes there is strong independent reason to believe are correct, so it was removed rather than shipped. A tool nobody has seen work is not a tool.
