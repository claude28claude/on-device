Lock a file with a password

Encrypt anything, a document, a photo, a folder you have zipped, so it can be sent safely, and unlock it again here.

What this tool cannot do

A forgotten password means the file is gone for ever. There is no recovery, no back door and nobody who can help, because there is no server that ever saw it. That is exactly what makes it secure.
