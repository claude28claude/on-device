Flatten a PDF

Turn a filled-in form into a fixed page, so nobody can change the answers afterwards.

What this tool cannot do

Flattening bakes in what the form fields show. It does not remove anything hidden elsewhere in the file, and it is not a substitute for redaction: text under a black box drawn by another program is still there. Redact a PDF is the tool that destroys content.

Options

What this does

A PDF form keeps its answers as editable fields. Flattening draws those answers permanently onto the page and removes the fields, so the document reads the same but can no longer be altered by filling it in again.

Choose a PDF to see how many fields it has.

Finished files land in the results tray at the bottom of the screen.
