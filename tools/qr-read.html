Read a QR code

See what a code actually says before you act on it. Drop in a screenshot or a photograph — the picture stays on this device.

Why you might want this rather than your camera

A phone camera usually reads a code and offers to open it in one movement, so the first time you see where it goes is after you have gone there. This shows you the address and nothing else happens. Nothing is opened, nothing is connected to, and no link here is clickable — you copy the text if you want it.

What this tool cannot do

It reads QR codes, not other barcodes — no shop barcodes, no Data Matrix, no PDF417. It works from a picture you already have, not from a live camera. A code that is badly out of focus, folded, or at a steep angle may not be readable at all; if that happens it says so rather than guessing.

Options

With the code outlined where it was found.

Puts a .txt file in the results tray as well as showing it here.

The reading library is fetched from this site the first time you use this tool, then kept.
