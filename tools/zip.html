Zip and unzip

Bundle files into a single zip, or open one and take the contents out.

What this tool cannot do

It can open password-protected zips and make them, but the zip format's own encryption is weaker than the Lock a file tool, which uses modern encryption. For anything that matters, lock the file instead.
